Dinaminis masyvas — pilnavertė std::vector alternatyva.

Realizuoja beveik visą std::vector interfeisą: member tipus, konstruktorius, elementų prieigą, iteratorius, talpos valdymą, modifikavimo operacijas ir ne-narius operatorius.

Architektūra
Klasė laiko tris rodykles, kaip ir tipinė std::vector realizacija:
begin_ → pradžia
end_ → po paskutinio elemento (size = end_ - begin_)
cap_ → po paskirtos atminties (capacity = cap_ - begin_)

Atmintis skiriama ir konstruojama atskirai: allocate() tik rezervuoja baitus, o objektai kuriami construct() metodu. Todėl reserve(1000) nesukuria 1000 objektų — tik paskiria vietą.

Augimo strategija
Pritrūkus vietos, talpa dvigubinama (arba nustatoma į 1, jei buvo 0). Toks koeficientas duoda amortizuotą O(1) push_back() sudėtingumą: n elementų įdėjimui reikia log₂(n) perskirstymų, o bendras kopijavimo darbas yra O(n).
Naudojimo pavyzdys
Vector<int> v = {1, 2, 3};
v.push_back(4);
v.insert(v.begin() + 1, 10); // {1, 10, 2, 3, 4}
for (int x : v) std::cout << x << " ";
Vector<int> v2(v); // kopija
Vector<int> v3(std::move(v)); // perkėlimas
