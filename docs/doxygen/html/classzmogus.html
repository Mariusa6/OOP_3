Smulkus aprašymas

ABSTRAKTI bazinė klasė — bendras bet kokio žmogaus aprašymas.

Laiko vardą ir pavardę bei apibrėžia interfeisą, kurį privalo realizuoti kiekviena išvestinė klasė.

Kodėl klasė abstrakti
Klasė padaryta abstrakti dviem nepriklausomais mechanizmais:
  1. Grynai virtualūs metodai (= 0) — galutinis(), print(), read(), tipas(). Kompiliatorius neleidžia kurti objektų iš klasės, kuri turi bent vieną neapibrėžtą virtualų metodą.
  2. protected konstruktoriai — prieinami tik išvestinėms klasėms. Tai antras apsaugos sluoksnis.
Naudojimo pavyzdys
// zmogus z; // KLAIDA: abstrakti klasė
// zmogus* p = new zmogus(); // KLAIDA: abstrakti klasė
studentas s("Jonas", "Jonaitis", {5, 6, 7}, 8); // OK
zmogus& z = s; // OK — nuoroda
std::cout << z.tipas() << "\n"; // "Studentas"
std::unique_ptr<zmogus> p =
std::make_unique<studentas>("Ona", "Onaite", {10}, 10); // OK
